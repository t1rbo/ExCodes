## 📖 What is ExCodes?

**ExCodes** — это автономная среда разработки в браузере, упакованная в один файл `index.html` без серверной части, зависимостей и трекинга. Проект создан при синергии человека (`t1rbo`) и ИИ (Qwen).

## ✨ Core Features

* **11 языков из коробки:** Python, JavaScript, C, C++, C#, Java, Go, Rust, R, SQL, Visual Basic с подсветкой синтаксиса и шаблонами.
* **Песочница Web Worker:** Безопасный запуск JS-кода в фоне и предпросмотр HTML/CSS/JS.
* **Шифрование AES-256-GCM:** Локальное хранилище данных с seed-фразой на 12 слов и экспортом `.excodes`.
* **Локальный ИИ-агент (Ollama):** Подключение к локальным моделям (`gemma4`, `qwen2.5-coder` и др.) с предпросмотром изменений (`diff`).
* **QA Lab и ZIP-архиватор:** 46 авто-тестов, история отмен на 50 шагов и экспорт проектов в `.zip` или автономный HTML.

## 🧠 Quick Start (Ollama)

Для запуска локального ИИ включите CORS в Ollama перед стартом:
* **Windows (PowerShell):** `$env:OLLAMA_ORIGINS="*"; ollama serve`
* **Linux / macOS:** `OLLAMA_ORIGINS="*" ollama serve`
